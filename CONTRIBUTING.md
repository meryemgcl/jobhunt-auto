# Contributing to JobHunt-Auto

Projeye katkıda bulunmak istediğiniz için teşekkürler!

## Geliştirme Süreci
1. Projeyi Fork'layın.
2. Yeni bir özellik dalı (branch) açın (`git checkout -b feat/harika-ozellik`).
3. Değişikliklerinizi commit edin (`git commit -m 'feat: yeni ozellik ekle'`).
4. Dalınızı push edin (`git push origin feat/harika-ozellik`).
5. Bir Pull Request açın.
